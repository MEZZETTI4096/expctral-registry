# Expctral Registry · demonstração

Vitrine, biblioteca e marketplace de shaders do ecossistema **Expctral**. Cada projeto roda ao vivo no navegador via WebGPU, e cada derivação preserva o crédito do autor original.

**Ao vivo:** https://mezzetti4096.github.io/expctral-registry/

## O que é esta publicação

Uma **demonstração estática e somente leitura**:

- Funcionam a exploração, a busca, as páginas de projeto com preview WebGPU ao vivo, a árvore de procedência, os perfis e o download dos `.rft` gratuitos.
- Login, compras, publicação e comentários precisam do servidor do Registry e aparecem desativados.
- Usuários, projetos e números são **dados de exemplo**. Pagamentos são sempre simulados.

Este repositório contém apenas o build gerado por `npm run build:pages`. O código-fonte não é publicado aqui.
